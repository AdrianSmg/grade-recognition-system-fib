> **Note on data privacy:** Due to data protection regulations (GDPR), this repository does not include any `.xlsx` or `.csv` files used during development or data import processes. These files may contain personal information about real students and university partners. If you want to run this project locally, you will need to provide your own data files following the structure described in the documentation.

---

> **Nota sobre protecció de dades:** Per complir amb la normativa de protecció de dades (RGPD), aquest repositori no inclou cap fitxer `.xlsx` ni `.csv` utilitzat durant el desenvolupament o els processos d'importació de dades. Aquests fitxers poden contenir informació personal d'estudiants reals i universitats conveniades. Si vols executar aquest projecte localment, hauràs de proporcionar els teus propis fitxers de dades seguint l'estructura descrita a la documentació.
